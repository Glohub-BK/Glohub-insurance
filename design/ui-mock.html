UI Proposal · v3 — 내 정보 · 담보 여력

같은 부품, 두 개의 무대
— 놓칠뻔 반응형·인증 시안

카드·뻐니·플럼·3D 그림자는 그대로 두고 배치 컨테이너만 화면 폭에 따라 바꿉니다. 모바일은 지금의 세로 스택 + 플로팅 탭바를 유지하고, 1024px 이상에서 탭바가 좌측 레일로 승격됩니다. 금액·계약 수는 전부 예시값입니다. v2: 조회=로그인 통합(카카오·네이버·구글), 한국신용정보원 공식 명칭, 통일 규격 통계 타일, AI 결과 플래그십 카드, 로그인 없는 보험 상식 섹션과 또래 비교 차트. v3: 내 정보(굿리치 골격 + 프로필 사진), 궁금증 TOP 5 메뉴, 담보 여력 도넛, 보험금 받은 내역과 「놓칠뻔」 탐지.

01 — Mobile · 조회 = 로그인

조회하려는 손이 곧 가입 의사다

체험은 로그인 없이, 내 보험을 실제로 조회하려는 순간에만 소셜 로그인을 요구합니다. 로그인 뒤 곧바로 한국신용정보원 연결로 이어지고, 이 계정이 보관·가족 공유의 기준이 됩니다. 보험 상식 등 정보 섹션은 로그인 없이 계속 열려 있습니다.

02 — Desktop ≥ 1024px

탭바가 레일로 승격된다

하단 탭 5개가 그대로 좌측 레일이 됩니다. 새 메뉴를 만들지 않으므로 모바일과 머릿속 지도가 같습니다. 본문은 홈에서 2단이 됩니다 — 왼쪽은 "행동"(질문·경고), 오른쪽은 "현황"(보험료·가족).

04 — AI 결과 · 플래그십

진단 결과가 이 앱의 얼굴이다

결과 카드에만 그라디언트·글로우·입체 타일을 몰아 씁니다. 다른 화면이 조용해야 이 화면이 터집니다. 금액 숫자는 그라디언트 텍스트, 담보 타일은 빛나는 테두리, 약관 인용은 플럼 리본 — 전부 CI 팔레트 안에서만.

05 — 보험 상식 · 또래 비교

로그인 없는 정보, 로그인해야 보이는 나

보험 상식 탭은 로그인 없이 전부 읽힙니다. 그 안의 「내 보험료, 또래는 얼마나 낼까?」 차트가 자연스러운 로그인 유도 장치입니다 — 또래 평균은 보여주고, 내 막대만 잠가둡니다.

또래 데이터는 초기에 공개 통계(보험연구원·통계청)로 시작하고, 사용자 누적 후 자체 분포로 교체한다. 차트 막대는 항상 그라디언트 — 단색 막대 금지.

06 — Loading

뻐니가 오가며 기다림을 알린다

모든 화면 전환·조회 대기에서 뻐니가 좌우로 오가고, 두 포즈가 번갈아 나타납니다. 멈춘 그림은 죽은 화면과 구분되지 않습니다 — 움직임이 곧 "일하는 중"의 신호입니다. 아래는 실제 동작입니다.

06 — Profile

얼굴이 있는 계정, 팔지 않는 메뉴

굿리치의 「내 정보」 골격 — 프로필 헤더 · 아이콘 4열 · 묶음 리스트 · 비교 배너 · 푸터 — 을 그대로 따르되, 프로필 사진을 넣어 일반 메뉴에서도 얼굴이 보이게 하고, 상품 추천·플래너 연결 같은 판매 동선은 넣지 않습니다. 우리는 가입시키는 앱이 아니라 이미 가진 걸 못 쓰고 넘어가지 않게 하는 앱이라서, 메뉴는 지금까지 계획한 기능만으로 채웁니다.

07 — Capacity

얼마 남았는지가 보여야 청구한다

계약과 담보는 「무엇을 가졌나」이고, 여기는 「얼마나 썼고 얼마나 남았나」입니다. 가입금액에서 이미 받은 보험금을 뺀 잔여를 도넛으로 세웁니다. 단, 한도의 성격이 담보마다 달라서 소진형·연간형·사고당형을 섞지 않고 따로 그립니다.

09 — Rules

상태·경로 규칙

로그인+연결아바타—내 계약·보장 맵·진단 · 또래 속 내 위치 · 가족 초대(카카오톡)

「내 보험 조회하기」·「가족 초대」가 로그인의 유일한 관문이다. 소셜 로그인(카카오·네이버·구글) 직후 한국신용정보원 연결로 이어진다. 연결 화면만은 데스크톱에서도 좁은 1단 — 자격증명 입력은 시선이 좁아야 안전하다.

10 — 확정

이번에 확정된 것

용어

사용자 문구는 한국신용정보원 공식 명칭. 내보험다보여는 계정 안내 괄호에서만.

인증

조회 = 로그인. 소셜 3종(카카오·네이버·구글) → 신용정보원 연결. 정보 섹션은 로그인 불필요.

표현

통계는 통일 규격 타일 · 차트는 그라디언트 · 화려함은 AI 결과 카드에만 집중.

내 정보

굿리치 골격 채택 + 프로필 사진(홈·레일·가족 목록 공통 반영). 판매 동선(추천플래너·상품추천) 미채택.

담보 여력

소진형·연간형·사고당형을 섞지 않고 그린다. 채워진 호 = 남은 여력. 근거 없으면 회색 「미확인」.

받은 내역

신용정보원엔 없음. 홈택스(실손 수령액) + 심평원(5년 진료내역) + 사용자 입력의 3원 구성, 각각 별도 동의.
