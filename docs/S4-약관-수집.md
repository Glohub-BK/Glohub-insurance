# S4 — 약관 조항 수집

AI 청구 화면의 "판단 근거 — 약관 원문"은 기본적으로 **예시 문구**다.
상품마다 약관이 다르므로, 가입한 상품의 약관을 넣어야 실제 조항으로 바뀐다.

## 1. 약관 파일 구하기

- 보험사 홈페이지 → 공시실/상품공시 → 가입한 상품명으로 검색
- 또는 보험사 앱 → 내 계약 → 약관 다운로드
- 생명보험협회·손해보험협회 공시실에도 상품별 약관이 있다

스캔 이미지 PDF 는 텍스트가 없어 조항이 잡히지 않는다. 텍스트 PDF 를 받는다.

## 2. 먼저 확인만 (`--dry`)

```bash
npm run terms:import -- ./약관.pdf --dry
```

```
파일        약관.pdf
조항        184개
  제1조(보험금의 지급사유) — 회사는 피보험자가 …
```

조항 수가 0 이거나 이상하면 저장하지 않는다. 파서가 틀리면 인용문이 통째로 엉킨다.

> PDF 는 pdfjs 로 읽는다. **별도 설치가 필요 없다.**
> (초기 버전은 poppler/pdftotext 를 썼지만, 윈도우에서 관리자 권한 설치가 필요해 걷어냈다.)

## 3. 저장

```bash
npm run terms:import -- ./약관.pdf \
  --insurer "DB손해보험" \
  --product "내생애든든종합보험" \
  --member "본인"
```

- 같은 파일을 두 번 넣으면 해시로 걸러 건너뛴다.
- 특정 계약에 붙이려면 `--policy <policy_id>`.

## 4. 화면에서 확인

`/ai` 에서 사고 문장을 넣어본다.

- 조항을 찾으면: 원문 + `출처 DB손해보험 내생애든든종합보험 · 제1조(보험금의 지급사유)`
- 못 찾으면: 예시 문구 + **"예시 문구입니다"** 경고

## 조항을 고르는 규칙

`src/lib/terms/match.ts` 에 사고 유형별 키워드가 있다.

- `must` 중 하나도 없으면 후보에서 뺀다
- `보상하지 않는`·`면책` 이 있으면 점수를 크게 깎는다 — **면책 조항을 근거로 보여주면 안 된다**
- 문턱(3점)을 넘지 못하면 **아무것도 고르지 않는다**. 엉뚱한 조항을 근거랍시고
  보여주는 것이 근거를 안 보여주는 것보다 나쁘다

## 하지 않는 것

- 조항을 요약해서 저장하기 — 요약하면 인용이 아니라 우리 해석이 된다
- 출처 없이 원문만 보여주기 — 어느 문서 몇 조인지 없으면 인용이 아니라 주장이다
- 약관 전문을 앱 화면에 재배포하기 — 판단에 쓰인 조항만 인용한다
