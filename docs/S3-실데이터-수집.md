# S3 — 데모 키로 실데이터 한 번 받기

데모 키는 **켜는 순간 한 달짜리 시계가 돌기 시작하고 하루 100건**이 끝이다.
되돌릴 수 없으므로 순서를 지킨다.

## 0. 켜기 전에 (샌드박스에서 확인)

`.env.local`

```
CODEF_ENV=sandbox

# ⚠ 클라이언트 ID·시크릿은 환경마다 다르다(CODEF 콘솔에서 각각 발급).
CODEF_SANDBOX_CLIENT_ID=...
CODEF_SANDBOX_CLIENT_SECRET=...
CODEF_DEMO_CLIENT_ID=...
CODEF_DEMO_CLIENT_SECRET=...

# 공개키만 계정당 하나로 공통이다.
CODEF_PUBLIC_KEY=...

DATABASE_URL=postgres://...
```

```bash
npm run dev
```

`/connect` 에서 아무 값이나 넣고 눌러본다. 샌드박스는 고정 응답이라 실제 계약을
건드리지 않는다. 여기서 화면 흐름(입력 → 인증 대기 → 완료)이 끝까지 도는지 본다.

## 1. 잠금 두 겹

실데이터 환경은 스위치를 켜야만 나간다. 실수로 한 번 누르는 사고를 막는 장치다.

```
CODEF_ENV=demo             # 이 값에 맞는 CODEF_DEMO_* 키를 앱이 골라 쓴다
CODEF_ALLOW_LIVE=true      # 이걸 켜지 않으면 조회가 거부된다
CODEF_DAILY_LIMIT=100      # 생략하면 100
```

`CODEF_ALLOW_LIVE` 가 없으면 앱은 `LIVE_NOT_ALLOWED` 로 거절한다.
하루 한도는 `sync_run` 기록으로 센다 — 앱을 껐다 켜도 카운트가 이어진다.

## 2. 남은 건수 확인

```bash
npm run codef:status
```

```
환경        demo — 데모 (실데이터 · 1개월 · 하루 100건)
실데이터    예
잠금        열림 (CODEF_ALLOW_LIVE=true)
오늘 사용   3 / 100건 (남은 97건)
```

## 2-1. 키가 살아 있는지 먼저 (한도 소모 없음)

```bash
npm run codef:ping
```

토큰 발급만 해본다. 계약 조회가 아니라 **하루 한도를 쓰지 않고** 내보험다보여 계정도
필요 없다. 여기서 실패하면 계정이 아니라 **키 문제**다 — 샌드박스 키와 데모 키는 다르다.

## 3. 조회

`/connect` → 내보험다보여 **아이디·비밀번호** 입력 → 휴대폰 인증 → `인증을 마쳤어요`.

- 비밀번호는 어디에도 저장하지 않는다. 서버 메모리에서 RSA 로 암호화되어 나가고 끝난다.
- 추가 인증(2-way)은 1차 응답의 `twoWayInfo` 를 **값 그대로** 되돌려 보내야 한다.
  값 하나만 달라도 대상기관이 세션을 버린다.
- 실패하면 화면에 사유와 **오류 코드**가 함께 뜬다. 같은 코드가 `npm run dev` 를 띄운
  터미널에도 `[connect] 실패 code=... env=...` 로 남는다(비밀번호는 절대 남지 않는다).

| 코드 | 뜻 | 할 일 |
|---|---|---|
| `LIVE_NOT_ALLOWED` | 실데이터 잠금이 잠겨 있음 | `.env.local` 에 `CODEF_ALLOW_LIVE=true` |
| `NOT_CONFIGURED` | 키가 없음 | `.env.local` 의 `CODEF_*` 세 개 확인 |
| `UNAUTHORIZED` / 토큰 실패 | **키가 이 환경 것이 아님** | `npm run codef:ping` 이 '키 출처' 를 알려준다. 샌드박스 키로 데모를 부르면 실패한다 |
| `CF-12100` | 아이디·비밀번호 불일치 | 내보험다보여 사이트에서 직접 로그인해 확인 |
| `CF-12827` | 아이디·비밀번호 **형식** 위반 | 6~12자 영숫자 / 9~20자 영문+숫자+특수 |
| `CF-12831` / `CF-00401` | 본인인증 미완료·만료 | 내보험다보여 사이트에서 본인인증(1년마다 갱신) |
| `DB_UNAVAILABLE` | DB 연결 실패 | `DATABASE_URL` 확인 |
| `DAILY_LIMIT` | 오늘 100건 소진 | 내일 |

## 4. 조회 후

```bash
npm run codef:status     # 몇 건 썼는지
```

가족 탭에서 구성원별 마지막 조회 시각을 본다. **조회는 가끔, 데이터는 항상** —
새 보험에 가입했을 때만 다시 조회한다. 절대 주기적으로 돌리지 않는다.
CODEF 문서는 과도한 호출 시 IP 차단을 경고한다.

## 하지 않는 것

- 배치·스케줄러로 자동 재조회 (IP 차단)
- 가족 계정을 대신 입력해 조회 (각자 자기 기기에서 인증한다)
- 실패했다고 연속 재시도 (서버가 5초 간격으로 끊는다)
